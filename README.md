# Login Pages Mobile Apps UI/UX

A beautiful Flutter login/signup page with animations, inspired by modern UI/UX design principles.

## Features

- ✨ Animated background blobs
- 🌸 Floating emoji decorations
- 🔄 3D card flip animation (login/signup)
- 👤 Animated avatar with emoji reactions
- 💫 Custom styled form fields
- ✅ Custom checkbox components
- 🚀 Primary button with sparkle effects
- 🔐 Social login buttons (Google, Apple)
- 📱 Responsive design

## Getting Started

### Prerequisites

- Flutter SDK: >=3.0.0
- Dart SDK: >=3.0.0

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/login_pages_mobile_apps_uiux.git
   ```

2. Navigate to the project directory:
   ```bash
   cd login_pages_mobile_apps_uiux
   ```

3. Install dependencies:
   ```bash
   flutter pub get
   ```

4. Run the app:
   ```bash
   flutter run
   ```

## Design Highlights

- **Glassmorphism**: The login card uses backdrop blur and semi-transparent backgrounds
- **Micro-interactions**: Form fields animate on focus, buttons have tap effects
- **3D Transforms**: Card flips with perspective transform
- **Gradient Accents**: Pink-to-lavender gradients throughout
- **Responsive**: Works on both mobile and tablet screens
